Integrated character sprite sheet

character_basic_2d.png: transparent PNG, 4 columns x 5 rows. Rows: idle, walk, run, jump, attack. Four frames per action. Used by the gameplay renderer via embedded data URI in both HTML builds.
frames/: individual transparent PNG frame exports.
Weapon rendering and all other gameplay features remain from the original project. Character art uses compact 2D tactical anime style; left-facing characters are mirrored by existing direction/weapon handling where applicable.
